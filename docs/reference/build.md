# MAINFRAME Build CLI Reference

**Static Binary Builder and Minimal Container Generator**

```bash
mainframe build <command> [options] <script>
```

## Commands

| Command | Description |
|---------|-------------|
| `static` | Create standalone script with all libraries inlined |
| `minimal` | Create minimal bundle with only required libraries |
| `container` | Generate Dockerfile for containerized execution |

## Options

| Option | Description | Default |
|--------|-------------|---------|
| `--target <arch>` | Target architecture (amd64, arm64, armv7) | native |
| `--output <dir>` | Output directory | ./dist |
| `--name <name>` | Override output name | script basename |
| `--strip-comments` | Remove comments to reduce size | false |
| `--minify` | Minify whitespace (aggressive) | false |
| `--manifest` | Generate build manifest JSON | false |
| `--quiet` | Suppress informational output | false |

## Static Build

Creates a single self-contained executable script with all MAINFRAME libraries inlined.

```bash
mainframe build static my-agent.sh
mainframe build static my-agent.sh --output dist/
mainframe build static my-agent.sh --strip-comments --manifest
mainframe build static my-agent.sh --minify --name my-tool
```

### Output Structure

```bash
#!/usr/bin/env bash
# =============================================================================
# MAINFRAME Static Build
# Generated: 2026-02-01T12:00:00Z
# Source: my-agent.sh
# Target: native
# =============================================================================

set -euo pipefail

# === Inlined: lib/common.sh ===
# ... all functions ...

# === Inlined: lib/json.sh ===
# ... all functions ...

# === Original Script: my-agent.sh ===
# ... agent code ...
```

### Size Optimization

| Flag | Effect |
|------|--------|
| `--strip-comments` | Removes comment lines (preserves structure) |
| `--minify` | Removes comments + whitespace (more aggressive) |

## Minimal Bundle

Creates a directory bundle with only the required libraries.

```bash
mainframe build minimal my-agent.sh
mainframe build minimal my-agent.sh --output dist/
```

### Bundle Structure

```
my-agent-bundle/
├── agent.sh           # Wrapped script with local lib paths
├── lib/               # Only required libraries
│   ├── common.sh
│   ├── json.sh
│   └── validation.sh
├── run.sh             # Entry point
└── manifest.json      # Build metadata (if --manifest)
```

### Running the Bundle

```bash
./my-agent-bundle/run.sh [args]
# or
bash my-agent-bundle/agent.sh [args]
```

## Container Build

Generates a complete Docker build context for containerized execution.

```bash
mainframe build container my-agent.sh
mainframe build container my-agent.sh --target arm64
```

### Container Structure

```
my-agent-container/
├── Dockerfile         # Optimized multi-stage build
├── docker-compose.yml # Ready-to-use compose config
├── build.sh           # Convenience build script
├── app-bundle/        # Minimal bundle (from build minimal)
│   ├── agent.sh
│   ├── lib/
│   └── run.sh
└── manifest.json      # Build metadata (if --manifest)
```

### Generated Dockerfile

```dockerfile
# Generated by mainframe build container
FROM --platform=linux/amd64 bash:5.2-alpine

# Install runtime dependencies
RUN apk add --no-cache curl jq

# Copy MAINFRAME runtime
COPY app-bundle/lib/ /opt/mainframe/lib/
ENV MAINFRAME_ROOT=/opt/mainframe

# Copy agent
COPY app-bundle/agent.sh /app/agent.sh
RUN chmod +x /app/agent.sh

ENTRYPOINT ["bash", "/app/agent.sh"]
```

### Building and Running

```bash
cd my-agent-container
./build.sh              # Build with tag :latest
./build.sh v1.0.0       # Build with specific tag

docker run --rm my-agent:latest [args]
docker compose up -d     # Background mode
```

## Build Manifest

When `--manifest` is specified, generates a JSON file with build metadata.

```json
{
  "name": "my-agent",
  "version": "1.0.0",
  "build_time": "2026-02-01T12:00:00Z",
  "source": "my-agent.sh",
  "type": "static",
  "target": "native",
  "size_bytes": 45000,
  "libraries_included": ["common.sh", "json.sh", "http.sh"],
  "functions_count": 150,
  "external_deps": ["curl", "jq"],
  "mainframe_version": "6.0.0",
  "build_tool_version": "1.0.0"
}
```

### Container Manifest (Additional Fields)

```json
{
  "type": "container",
  "base_image": "bash:5.2-alpine",
  "alpine_packages": ["curl", "jq"],
  "files": ["Dockerfile", "docker-compose.yml", "build.sh", "app-bundle/"]
}
```

## Dependency Detection

The build tool automatically detects:

### MAINFRAME Libraries

- `source` statements for `$MAINFRAME_ROOT/lib/*.sh`
- `mainframe_load "library"` calls
- Transitive dependencies (libraries that source other libraries)

### External Commands

Detected commands mapped to Alpine packages:

| Command | Alpine Package |
|---------|----------------|
| curl | curl |
| jq | jq |
| git | git |
| openssl | openssl |
| ssh/scp | openssh-client |
| dig/nslookup | bind-tools |
| python3 | python3 |
| node | nodejs |
| redis-cli | redis |

## Cross-Architecture Support

Build for different CPU architectures:

```bash
# AMD64 (x86_64) - default
mainframe build container my-agent.sh --target amd64

# ARM64 (Apple Silicon, AWS Graviton)
mainframe build container my-agent.sh --target arm64

# ARMv7 (Raspberry Pi)
mainframe build container my-agent.sh --target armv7
```

The generated Dockerfile includes the appropriate `--platform` directive.

## Examples

### CI/CD Pipeline Script

```bash
#!/usr/bin/env bash
# Build static binary for deployment
mainframe build static ./scripts/deploy.sh \
  --output ./artifacts \
  --strip-comments \
  --manifest \
  --name deploy-tool

# The single file can be copied to any server
scp ./artifacts/deploy-tool user@server:/opt/tools/
```

### Multi-Architecture Container Build

```bash
#!/usr/bin/env bash
# Build for both AMD64 and ARM64
for arch in amd64 arm64; do
  mainframe build container ./agent.sh \
    --target "$arch" \
    --output "./dist/$arch" \
    --manifest
done

# Push multi-arch manifest
docker buildx build --platform linux/amd64,linux/arm64 \
  -t myregistry/agent:latest --push ./dist/amd64/agent-container
```

### Development Bundle

```bash
# Create portable bundle for testing
mainframe build minimal ./dev-agent.sh --output /tmp/test-bundle

# Run in isolation
cd /tmp/test-bundle/dev-agent-bundle
./run.sh --debug
```

## Best Practices

1. **Use static builds** for single-file deployments (CI/CD, cron jobs)
2. **Use minimal bundles** for development and debugging
3. **Use container builds** for microservices and Kubernetes
4. **Always generate manifests** for audit trails and reproducibility
5. **Strip comments** for production to reduce payload size
6. **Test built artifacts** before deployment
