## Historical material

Documents under `docs/research/`, `docs/designs/`, `docs/analysis/`, and
`docs/reviews/`, plus versioned engineering plans, prior review reports, and the
legacy paradigms guides, preserve project history. They may
contain old counts, targets, names, or implementation assumptions. Use the root
README, installation guide, security policy, generated registry, and current
integration matrix for supported behavior.

The repository-only `docs/VALUE_PROOF.md` and
`docs/MAINFRAME_Technical_Report.md` are explicitly quarantined historical
research. Their unverified outcome claims are not current evidence, and both
files are deliberately excluded from release archives.
